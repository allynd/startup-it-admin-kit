Name:
Startup IT Admin Kit

Tagline:
Practical IT templates for small teams without a full IT department.

Description:
A template bundle for founders, ops managers, solo IT admins, and small teams who need cleaner IT processes for onboarding, offboarding, SaaS access reviews, asset inventory, laptop deployment, Google Workspace, Microsoft 365, incident reporting, SOC 2 evidence tracking, and basic security settings.
